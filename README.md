# Attentive

A live lecture feedback tool. Students pin the slide they are confused about, anonymously, and the lecturer sees where the class is losing the thread while the lecture is still running.

## Status

Early development. This repository is the full product build, starting from the D4 prototype. Deployment is out of scope for now.

## Planned stack

- Client: React with Vite and TypeScript
- Server: Node.js with Express
- Database: SQLite
- Live updates: server-sent events

## Principles

- Anonymous by design: pins are stored as slide counts with no student identifier.
- Accessible: keyboard use, screen reader support, English and Urdu (right-to-left), adjustable text size.
- Works on phones and on the web.
